# Política de seguridad

Este documento describe cómo notificar vulnerabilidades de seguridad en el componente de código abierto de [dataspace.es](https://dataspace.es), desarrollado por GrayHats S.L.U.

## Versiones soportadas

Mientras el proyecto se mantenga en la serie `0.y.z`, solo la última versión publicada recibe correcciones de seguridad.

## Notificación de vulnerabilidades

Si crees haber encontrado una vulnerabilidad, comunícala de forma privada a **info@dataspace.es**. No abras incidencias ni pull requests públicos con los detalles.

Incluye, si es posible, el componente y la versión afectados, los pasos para reproducirla y su impacto estimado. No adjuntes credenciales ni datos personales reales.

Acusaremos recibo, evaluaremos el reporte y, una vez disponible la corrección, coordinaremos contigo la divulgación.

## Historial

Las correcciones de seguridad se recogen en [`CHANGELOG.md`](CHANGELOG.md) y se detallan en el [registro de vulnerabilidades](docs/security/vulnerability-register.md).
